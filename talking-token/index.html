Talking Token

すべてのAI利用を、一つに。

ChatGPTも、Claudeも、Claude Codeも。バラバラだった使用量・費用・契約プランを、ひとつの画面で管理する。AIとの会話から生まれるトークンを、まとめて見える化します。

※ 登録不要・ブラウザで完結する設計です。会話本文をサーバーに送ることはありません。

Features

できること（予定）

01

一元管理ダッシュボード

AI別・日別の使用量と費用を1画面に。実測と推定を分けて表示するので、数字の根拠が分かります。

02

ログ・履歴のインポート

Claude Codeのログと、ChatGPTの公式エクスポートを読み込みます。処理はすべてブラウザ内です。

03

契約プラン管理

契約中のプラン・月額・更新日を一覧に。合計額と、更新が近いプランがすぐ分かります。

04

適正チェック

「定額の方が得か、従量の方が得か」「上限に当たる理由は何か」を、管理データから提示します。

プライバシー設計

会話履歴には、仕事の内容や個人情報が含まれます。Talking Tokenはブラウザ内処理を原則とし、会話本文をサーバーへ送信しません。データはあなたの端末の中だけに保存されます。
